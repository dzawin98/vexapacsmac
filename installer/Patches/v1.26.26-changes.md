# VEXAPACS-RIS V1.26.26 — Senyapkan spam [INFO] OpenJPEG di console viewer

Berisi seluruh perbaikan V1.26.25 + perbaikan console viewer di rilis ini.

## Masalah

Saat membuka studi yang berisi citra JPEG 2000, console browser dibanjiri baris
`[INFO]` dari OpenJPEG (decoder JPEG2000 di dalam WASM). Baris-baris itu dicetak
lewat `print`/`printErr` bawaan Emscripten, jadi tampak seperti error walaupun
dekode gambar sebenarnya berhasil — user melihat console penuh dan menganggap
viewer rusak.

Sumber spam ada di `@cornerstonejs/dicom-image-loader`, pada pembuatan modul
OpenJPEG:

```
dist/esm/shared/decoders/decodeJPEG2000.js
```

## Perbaikan

Panggilan `openJpegFactory({...})` diberi override `print` dan `printErr` supaya
output internal OpenJPEG tidak lagi diteruskan ke console:

```js
const openJpegModule = openJpegFactory({
    locateFile: (f) => { ... },
    // Silence OpenJPEG's internal [INFO] prints that flood the console.
    print: () => {},
    printErr: () => {},
});
```

Karena `node_modules` tidak ikut di-commit, perbaikan dipasang sebagai **patch
permanen** (`patch-package`) supaya bertahan terhadap `npm install`:

| Aplikasi | Versi loader | File patch |
|---|---|---|
| DESKTOP VIEWER | `@cornerstonejs/dicom-image-loader@5.1.4` | `DESKTOP VIEWER/patches/@cornerstonejs+dicom-image-loader+5.1.4.patch` |
| MOBILITY VIEWER | `@cornerstonejs/dicom-image-loader@2.1.16` | `MOBILITY VIEWER/patches/@cornerstonejs+dicom-image-loader+2.1.16.patch` |

Keduanya juga mendapat `"postinstall": "patch-package"` di `package.json`
(plus `patch-package` dan `postinstall-postinstall` sebagai devDependency),
sehingga patch ikut terpasang otomatis setiap `npm install`.

## Verifikasi

Patch benar-benar masuk ke bundel produksi (bukan hanya di `node_modules`):

| Bundel | File | `print:()=>{},printErr:()=>{}` |
|---|---|---|
| DESKTOP VIEWER `dist` | `assets/decodeImageFrameWorker-CDHFBQjC.js` | 1 (ada) |
| MOBILITY VIEWER `dist` | `assets/decodeImageFrameWorker-BNVdltfa.js` | 1 (ada) |
| Payload installer — PRIMARY VIEWER | `installer/payload/app/PRIMARY VIEWER/dist/...` | 1 (ada) |
| Payload installer — MOBILITY VIEWER | `installer/payload/app/MOBILITY VIEWER/dist/...` | 1 (ada) |

`npm run postinstall` di kedua aplikasi melaporkan patch terpasang tanpa error:

```
patch-package 8.0.1
Applying patches...
@cornerstonejs/dicom-image-loader@5.1.4 ✔
```

Build installer selesai dengan `Successful compile` dan `EXIT=0`.

## Catatan

Spam console hanya muncul pada studi JPEG 2000. Studi JPEG baseline tidak
terpengaruh, karena jalurnya berbeda (jpeg-js, bukan OpenJPEG).
